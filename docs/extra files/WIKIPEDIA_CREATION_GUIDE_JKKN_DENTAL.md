> Oru topic notable — atha pathi **reliable sources** la **significant coverage** irunthalae, antha sources **independent** ah irukkanum (subject kitta connection illa).

| Condition | Meaning | JKKN Dental Assessment |

## 4. COI RULES — CONFLICT OF INTEREST

### COI Na Ena?

JKKN la work panra, padikra, or JKKN ku paid ah iruntha — JKKN Wikipedia articles edit panra pothu unakku **conflict of interest** iruku. Wikipedia ithai romba seriously edukuthu.

**COI apply aagum — ne:**
- Employee ah iruntha (any role — admin, faculty, marketing)
- Student ah iruntha (current or recent)
- Trustee or governing body member ah iruntha
- JKKN Wikipedia article create panra ku paid ah iruntha
- Vendor/partner with financial ties ah iruntha

### WP:PAID Na Ena?

Wikipedia article create/edit panrathu unka job oda part ah iruntha (partially ah irunthaalum), **declare pannanume pananum**. Ithu Wikimedia Foundation Terms of Use requirement — optional illa.

**Paid editing declare pannama iruntha = Terms of Use violation = permanent account ban.**

## 6. ARTICLE STRUCTURE & WIKIPEDIA MARKUP

### Wikipedia Markup Basics

Wikipedia own markup language use pannum — "wikitext" nu solvaanga. Essentials itho:

**Headings:**
```wikitext
== Main Section ==          (Level 2 — main sections ku use pannu)
=== Subsection ===          (Level 3 — sections ulle use pannu)
==== Sub-subsection ====    (Level 4 — romba avanma vena)
```
**Rule:** Level 1 (single `=`) never use pannathae. Article title automatically Level 1. `==` la start pannu.

**Text Formatting:**
```wikitext
''italic text''             (rendu single quotes each side)
'''bold text'''             (moonu single quotes each side)
'''''bold italic'''''       (five single quotes each side)
```

**Lists:**
```wikitext
* Bullet point 1            (asterisk — unordered ku)
* Bullet point 2
** Sub-bullet               (double asterisk — nesting ku)

# Numbered item 1           (hash — ordered ku)
# Numbered item 2
```

**Internal Links (vera Wikipedia articles ku):**
```wikitext
[[Komarapalayam]]                           → Komarapalayam article ku link
[[Namakkal district|Namakkal]]              → "Namakkal" display aagum but "Namakkal district" ku link
[[Tamil Nadu Dr. MGR Medical University]]    → University article ku link
[[Dental Council of India]]                  → DCI article ku link
```

**External Links (External links section la mattum):**
```wikitext
[https://dental.jkkn.ac.in/ Official website]
```

**References (Citations):**

## 7. NPOV — NEUTRAL POINT OF VIEW

### NPOV Na Ena?

NPOV (Neutral Point of View) Wikipedia oda core content policy. Meaning:
- **Describe pannu, advocate pannathae** — College pathi observer maari elutha, promoter maari illa
- **Sources illama superlatives use pannathae** — Independent source sollathu na mattum "best" or "leading" sollu
- **Facts ah pesakoothu** — "Excellent facilities" nu sollama, "200 dental chairs and 100 beds" nu sollu
- **Negative information um include pannu** — Independent sources problems report pannirunthalae, avayum add pananum

### Golden Rule

**College brochure la varum sentence Wikipedia la varakoodathu.**

### NPOV Writing Techniques

| Technique | Enga Apply Panrathu |
|-----------|---------------------|
| **Specific numbers use pannu** | "Large hospital" nu sollama → "200+ dental chairs and 100+ inpatient beds" |
| **Source cite pannu** | "Prestigious accreditation" nu sollama → "NAAC accreditation with grade 'A'[ref]" |
| **Adjectives remove pannu** | "Excellent," "outstanding," "world-class," "state-of-the-art," "cutting-edge" delete pannu |
| **Attribution koodu** | "Highly ranked" nu sollama → "According to NIRF 2024, ranked Xth in dental[ref]" |
| **Third person use pannu** | "We," "our," "us" never use pannathae — "the college," "the hospital," "the institution" use pannu |
