P1 — Urgent for this admission season

1

No on-site lead capture form — every CTA leaves the site or opens phone/email

P1

Enna miss aaguthu

There is no enquiry / "request a callback" form anywhere on the site. Every admission CTA is either tel:+919345855001, mailto:, or an external link to https://www.jkkn.ai/apply/jkkn-admission-2026. The Contact page (app/contact/page.tsx) has phone/email cards and an external Apply button — but no form fields.

Yen important

During season, most visitors are exploring, not ready to formally apply on a third-party portal. A student/parent on mobile who wants "JKKN-la oru call back venum" has no low-friction option. External jump = drop-off + zero lead data captured = no follow-up by the admission team. This is the single biggest conversion leak in the funnel.

Epdi add pannanum

Create a small client component components/AdmissionEnquiryForm.tsx (Name, Phone, Course interest BDS/MDS, City, optional NEET score) posting to a Supabase table (Supabase already wired via lib/supabase/) or an API route. Embed it: (a) as a section on app/admissions/page.tsx + /admissions/bds/ + /admissions/mds/, (b) on app/contact/page.tsx "Apply Online" block, (c) optionally as a sticky/slide-in during season. Keep the external Apply Now as the secondary CTA. (CLAUDE.md notes "No CRM — leads managed manually" — a DB table fixes exactly that.)

2

Header Admission menu has broken links + the best pages are not linked

P1

Enna miss aaguthu

Both nav definitions — data/content.ts (lines ~175–189) and lib/navigationMenuLink.ts (lines ~272–286) — point the Admission submenu to /admissions/admission-process-guidelines and /admissions/admission-process-guidelines/admission-criterion-in-others. Neither page exists (no such folder under app/admissions/) — these 404 when clicked. Meanwhile the crown-jewel pages — /admissions/bds/, /admissions/mds/ (sitemap priority 0.95), /fees-structure/, the real /admissions/admission-criteria/, /admission-process/, and a direct Apply Now — are absent from the menu entirely.

Yen important

The highest-converting, highest-SEO admission pages are effectively orphaned from primary navigation — only reachable via resource cards on the hub or the sitemap. During season, a parent opening the menu sees a thin, partly-broken Admission list. 404s on a money menu hurt trust and crawl budget.

Epdi add pannanum

In data/content.ts and lib/navigationMenuLink.ts: remove/repoint the two admission-process-guidelines entries to the real /admissions/admission-criteria/, and add submenu items: BDS Admission (/admissions/bds), MDS Admission (/admissions/mds), Fee Structure (/fees-structure), Admission Process (/admission-process), and an Apply Now entry to the external portal. Re-test on Header (desktop mega-menu) and BottomNav (mobile).

3

Main /admissions/ page canonical (+ OG + speakable) points to a 301-redirected URL

P1

Enna miss aaguthu

In app/admissions/page.tsx: alternates.canonical, openGraph.url, the speakable url, and the breadcrumb item all use https://dental.jkkn.ac.in/admission/ (singular). But next.config.ts 301-redirects /admission → /admissions. So the page's self-canonical points to a URL that immediately redirects.

Yen important

A canonical that resolves to a redirect is a conflicting signal — Google may ignore it, split equity, or pick its own canonical. On the most important admission hub page, that risks the page not ranking under its true URL for "JKKN dental admission".

Epdi fix pannanum

Change all four occurrences to https://dental.jkkn.ac.in/admissions/. (BDS/MDS sub-pages already use the correct plural — only the hub + app/admissions/prospectus/page.tsx breadcrumb, which uses /admission/prospectus/, need fixing.)

4

/admission-process/ page is stale: 2025 dates, wrong spec count, invalid schema

P1

Enna miss aaguthu

In app/admission-process/page.tsx: badge says "Admissions Open 2025"; "Important Dates 2025" table lists May/June/July/August 2025; FAQ schema claims "JKKN offers 9 MDS specializations" (correct is 5 — 9 is the department count); and the HowTo.estimatedCost.value is the literal string "[PLACEHOLDER – Contact admissions for current fee structure]" (invalid for a MonetaryAmount).

Yen important

This page ranks/served for "admission process" queries and is indexed. Last-year dates make the college look inactive during a live 2026-27 cycle; the "9 specializations" error is a factual contradiction AI engines (ChatGPT/Gemini/Perplexity) will surface; the placeholder cost can trigger invalid structured-data warnings in Search Console.

Epdi fix pannanum

Update copy to 2026-27, align the dates table with the BDS page's importantDates (single source), correct "9 → 5 specializations" in the FAQ schema, and either set a real numeric estimatedCost or remove that property. Also decide: this page overlaps heavily with /admissions/ — see P2 #9 (consolidate vs differentiate).

P2 — Important (high search demand / trust)

5

No NEET cutoff information anywhere — high-volume query left uncaptured

P2

Enna miss aaguthu

Every page defers NEET cutoff to "contact admissions" (e.g. BDS FAQ schema, admission-criteria FAQ). No indicative or previous-year cutoff/closing-rank table exists.

Yen important

"JKKN dental NEET cutoff", "BDS cutoff Tamil Nadu management quota" are among the most-searched admission queries. Competitors (CollegeDunia/Shiksha) capture this traffic. An on-page indicative table = big organic + AEO win and answers the #1 student question.

Epdi add pannanum

Add a "NEET Cutoff (Indicative)" section + table on /admissions/bds/ and /admissions/mds/ with category-wise previous-year closing ranks/marks (clearly labelled "indicative, varies yearly"), backed by collegeFacts.ts. Wrap in a small schema-friendly FAQ.

6

Fee transparency gaps — MDS range too wide, stipend/EMI/loan unstated

P2

Enna miss aaguthu

BDS fees are concrete (₹4.5L day-scholar / ₹5.5L with hostel, MQ). But MDS shows only "₹8L–₹15L / year — contact admissions", stipend is "as per norms" (no figure), NRI fee is "as per DCI norms", and "installment options available" has no detail. No education-loan / EMI guidance.

Yen important

Affordability is parents' #1 decision factor. Vague ranges create friction and push them to call competitors who publish clear numbers. Loan/EMI info is a known conversion accelerator for professional courses.

Epdi add pannanum

On /admissions/mds/ add specialization-wise fee + a stated stipend figure; add an "Education Loan & EMI" block (partner banks, indicative EMI) on /fees-structure/ (app/fee-structure/page.tsx) and link it from BDS/MDS fee sections.

9

P2

Enna miss aaguthu

Three pages cover essentially the same "process + eligibility": the strong /admissions/ hub, the stale /admission-process/, and the thin /admissions/admission-criteria/. All carry HowTo/FAQ on the same intent.

Yen important

Keyword cannibalization splits ranking signals for "admission process / criteria / eligibility" and dilutes which URL Google trusts.

Epdi fix pannanum

Pick /admissions/ as the canonical hub. Either 301 /admission-process/ into it, or refresh + clearly differentiate it (e.g. "step-by-step counselling guide") and cross-link tightly. Make admission-criteria the dedicated eligibility deep-page and interlink.

P2

Enna miss aaguthu

BDS Course schema has aggregateRating 4.5 (120 ratings/85 reviews) and MDS 4.5 (85/60) — but no corresponding reviews are shown on the pages.

Yen important

Google's policy requires ratings to reflect content visible on the page; unverifiable ratings can trigger a structured-data manual action and loss of rich results — bad during season.

Epdi fix pannanum

Either surface real reviews/testimonials on the same page (link the existing /testimonials/ data into the admission funnel) or remove aggregateRating until genuine review data is displayed.
