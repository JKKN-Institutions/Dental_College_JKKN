Internal linking in 60 seconds (for whoever picks this up)

An internal link = a <Link> from one page on our domain to another page on the same domain. Google’s crawler walks the site by following these links, so a page with no inbound links is nearly invisible. Three rules drive every task below:

1 • Discoverability — every important page must be reachable in ≤3 clicks from Home.
2 • Authority flow — strong pages (Home, footer-on-every-page) should link to money pages (admissions, BDS, MDS, fees).
3 • Anchor text — the clickable text must describe the target (“BDS Admission 2026”, never “click here”).

Today: the Footer has 0 internal links, the Admission menu is missing the real BDS/MDS/process pages, and ~11 money pages are near-orphans. These 6 tasks fix all three.

D3 • Reusable <RelatedLinks> component

3

One component to add sibling + cross-cluster links anywhere

P1Effort: Low (1–2h)Impact: High
NEW file components/RelatedLinks.tsx
import Link from 'next/link';

interface RelatedLink { label: string; href: string; }
interface RelatedLinksProps { title?: string; links: RelatedLink[]; }

export default function RelatedLinks({ title = 'Related pages', links }: RelatedLinksProps) {
  return (
    <nav aria-label={title} className="mt-12 rounded-xl border border-[#e6e6d8] bg-[#FBFBEE] p-6">
      <h2 className="mb-4 text-lg font-bold text-[#006837]">{title}</h2>
      <ul className="grid gap-3 sm:grid-cols-2 lg:grid-cols-3">
        {links.map((l) => (
          <li key={l.href}>
            <Link
              href={l.href}
              className="block rounded-lg border border-[#7cb983] bg-white px-4 py-3 text-sm font-semibold text-[#002309] transition-colors hover:bg-[#7cb983] hover:text-white"
            >
              {l.label}
            </Link>
          </li>
        ))}
      </ul>
    </nav>
  );
}
  • Server component (no "use client") — pure markup, brand colors hardcoded per theme tokens.
  • Used in D4. Place near the bottom of a page’s main content, before <Footer>.

D6 • Canonical-URL linking rule + audit

6

Never link to a URL that 301-redirects

P3Effort: Low (1h)Impact: Medium

Linking to a redirected URL wastes a hop and dilutes link equity. Always link to the canonical target with a trailing slash.

Use (canonical)Never link to (redirects)
/admissions/… (plural)/admission/… (singular)
/academics/details-of-academic-programs/bds//bds/
/academics/details-of-academic-programs/mds//mds/
/fees-structure/ (plural)/fee-structure/ (singular)
Audit command (run from repo root) — finds any non-canonical internal hrefs
grep -rnE "href=\"/(bds|mds|fee-structure|admission)/" app/ components/ data/ lib/
  • Trailing slash is required (trailingSlash: true). Use /contact/, not /contact.
  • Use relative hrefs in <Link> (/admissions/bds/), not absolute https://….
